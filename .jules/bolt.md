## 2024-05-18 - Avoid unnecessary serde_json::Value roundtrips
**Learning:** For efficient JSON validation on hot paths without allocating full syntax trees, use `serde_json::from_str::<serde::de::IgnoredAny>` rather than parsing directly into `serde_json::Value`. To avoid unnecessary parse-and-serialize roundtrips and deep copies when sending pre-rendered JSON strings in HTTP requests, use `request.binary(bytes::Bytes::from(json.clone()))` with a manually set `content-type` header instead of the `.json()` or `.text()` builder methods. Note that `json.clone()` on a `&String` is an O(N) memory allocation and copy, but it is still much faster than a full JSON roundtrip.
**Action:** Replace `serde_json::from_str::<serde_json::Value>` with `serde_json::from_str::<serde::de::IgnoredAny>` for validation where the `Value` is not used, and use `Bytes::from` via the `binary()` request method for sending raw JSON strings.
